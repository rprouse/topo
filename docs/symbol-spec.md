# Symbol spec

Starting values for the map's symbology. `make project-init` generated `qgis/fernie.qgs` from these (the values live in `pipeline/style.py`). After that, the QGIS project is the source of truth: restyle in QGIS desktop, then update this file to match, so it stays a readable record of the design.

Sizes are on paper: millimetres for lines and symbols, points for text.

## Print rules

- **Minimum line weight: 0.10–0.15 mm.** Thinner lines vanish or break up on synthetic stock. The grid and thin contours are 0.10–0.12 mm, the thinnest allowed.
- **Minimum text: 6.5 pt.** Contour, spot-height, trail and road labels use exactly this.
- **Font: Noto Sans** (regular, bold, italic). Install it on every machine that edits the project. A missing font silently falls back to something else and moves every label.
- **Halos** are white, 0.5–0.8 mm, at 85% opacity. Use them just enough to lift text off contours.
- **Test in greyscale.** The map should still read without colour.

## Terrain

| Element | Symbol |
|---|---|
| Hillshade | Multiplied over the landcover tints at 45% strength. Keep it subtle; most first attempts are too dark. In QGIS this is done as a black-to-transparent colour ramp with normal blending, which is the same thing mathematically. **Don't use a Multiply blend mode:** in PDF export it drops italic label fonts. |
| Contour | Brown `#a0623a`, 0.12 mm |
| Index contour | Brown, 0.25 mm, labelled in brown 6.5 pt, on the line |
| Spot height | Black dot 0.6 mm, height 6.5 pt |

Contour interval and index frequency are set in `config/map.yaml`.

## Vegetation and land

Flat tints, no outlines: forest `#dcebc8`, scrub `#e7efcf`, heath `#ecefd6`, grass `#f1f4dc`, rock `#e6e1da`, scree `#ebe6de`, glacier `#eaf4fb`, farmland `#f3f0dc`, urban `#ebe4dc`, industrial `#e2dcd8`, quarry `#e0d8cf`, cemetery `#dbe6cf`, park and golf `#d3e8bd`. Check that contours still read through the forest tint. Buildings are `#4d4d4d`.

|---|---|

| Paved road | Pale yellow `#fff3a6` 0.50 mm, black casing 0.75 mm |

## Trails

Trails are the reason people buy the map, so they get the strongest contrast: red and black dashes by difficulty.

| Difficulty | Symbol |
|---|---|
| Easy | Red `#d7191c` 0.35 mm, long dash 1.6 / 0.6 |
| Moderate | Red 0.35 mm, short dash 0.8 / 0.6 |
| Difficult | **Black** 0.35 mm, short dash 0.8 / 0.6 |
| Not graded | Red 0.35 mm, dotted 0.35 / 0.5 |
| Paved path | Red 0.30 mm, solid |
| Closed | Black × every 8 mm over the trail |

Difficulty comes from OSM `sac_scale`, overridden in `authored/corrections.gpkg`. Trail names are 6.5 pt dark red `#8b1a1a`, along the line.

## Other lines

Railway: black 0.5 mm with white 3 / 3 dashes. Ski lift: black 0.3 mm. Power line: grey `#6e6e6e` 0.15 mm. Park or protected area: green `#3d8b37` dashed 0.5 mm outline.

## Place names

Bold, no symbol: city 14 pt, town 11, village 9, suburb 8, hamlet and neighbourhood 7.5, locality 7. Official names of ridges, valleys and parks that no OSM feature carries are labelled in italic 7.5 pt brown `#5a4632`.

## Label priorities

Highest wins when labels compete: places 10, peaks 9, lakes and official names 8, streams 7, trails 6, roads 5, spot heights and other POIs 4, contours 1.

## Collar

The collar is generated by `pipeline/layout.py`:
- **Title band:** side title 22 pt bold; subtitle, scale and edition 9 pt.
- **Collar band, four columns:**
  1. scale bar (km), scale and contour note, grid note, declination diagram (TN, GN, MN) and text;
  2. attribution, generated from `config/sources.yaml`;
  3. disclaimer;
  4. edition and data date.
- **Grid:** 1 km UTM, black 0.10 mm, labelled in km outside the frame, 6.5 pt.
- **Legend:** a box over the map corner set by `layout.legend_corner`, 6.5 pt.
